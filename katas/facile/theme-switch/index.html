Kata facile

Thème clair / sombre

Un bouton doit basculer la page entre une ambiance claire et une ambiance sombre.

Attendu

  • Ecouter le clic sur le bouton.
  • Ajouter ou retirer une classe sur la page.
  • Observer comment cette classe modifie les variables CSS.
  • Mettre à jour le texte du bouton.
  • Mettre à jour aria-pressed.

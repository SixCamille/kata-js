# Voiture au clic

## Objectif

Declencher la traversee de la fenetre par une voiture lorsque l'utilisateur clique sur un bouton.

## Notions de cours

- Une classe CSS peut demarrer une animation.
- JavaScript peut bloquer ou reinitialiser un etat pendant l'animation.
- Un texte de bouton peut indiquer l'action en cours.

## Travail attendu

- Cliquer sur le bouton lance la voiture.
- La voiture traverse la route.
- L'animation peut etre relancee apres la fin.
- Le bouton ne doit pas empiler plusieurs departs incoherents.

## Contraintes

- Ne pas deplacer la voiture avec une boucle JavaScript si l'animation CSS suffit.
- Utiliser JavaScript pour piloter l'etat.

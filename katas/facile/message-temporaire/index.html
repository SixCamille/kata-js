Kata facile

Message temporaire

Un clic doit afficher une notification, puis celle-ci doit disparaitre toute seule.

Attendu

  • Ecouter le clic sur le bouton.
  • Afficher la notification avec une classe.
  • Utiliser setTimeout() pour la masquer.
  • Eviter que plusieurs timers se contredisent.

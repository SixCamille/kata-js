Kata facile

Afficher / masquer

Au clic, le bouton doit alterner entre l'affichage et le masquage du mot de passe.

Attendu

  • Changer le type de l'input entre password et text.
  • Mettre a jour le texte du bouton.
  • Memoriser l'etat avec un booleen.

Notions du pense-bete

Selection DOM

querySelector recupere le premier element qui correspond au selecteur CSS.

const field = document.querySelector("input");
const button = document.querySelector("button");

Evenements et conditions

Un clic declenche une fonction. Une condition choisit quoi faire selon l'etat actuel.

button.addEventListener("click", function () {
  if (isVisible) {
    // cas visible
  }
});

Specifique au kata

Type d'un input

Le champ peut alterner entre un affichage masque et un affichage lisible.

field.type = "text";
field.type = "password";

Etat booleen

Un booleen memorise si le mot de passe est actuellement visible.

let isVisible = false;
isVisible = !isVisible;

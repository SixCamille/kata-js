# Afficher / masquer un mot de passe

## Objectif

Rendre un champ de mot de passe plus ergonomique en permettant a l'utilisateur d'afficher ou masquer sa saisie.

## Notions de cours

- Un `input` de type `password` masque la valeur saisie.
- Un `input` de type `text` affiche la valeur saisie.
- Un bouton peut modifier un attribut HTML via JavaScript.
- Un booleen permet de memoriser un etat : visible ou masque.

## Travail attendu

Au clic sur le bouton :

- si le mot de passe est masque, l'afficher ;
- si le mot de passe est visible, le masquer ;
- modifier le texte du bouton pour indiquer l'action suivante ;
- garder un code lisible avec des noms de variables explicites.

## Contraintes

- Ne pas modifier le HTML fourni sauf si necessaire.
- Utiliser `querySelector`.
- Utiliser `addEventListener`.
- Ne pas utiliser de bibliotheque externe.

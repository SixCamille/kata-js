# Ressources

## Lire et modifier le type d'un input

```js
const field = document.querySelector("input");

field.type = "text";
field.type = "password";
```

## Memoriser un etat

```js
let isVisible = false;

isVisible = true;
isVisible = false;
isVisible = !isVisible;
```

## Changer le texte d'un bouton

```js
button.textContent = "Masquer";
```

Bouton J'aime

Le bouton doit alterner entre aimé et non aimé, puis ajuster le compteur.

Le clic ne fait pas toujours la même chose : il dépend de l'état actuel. Si le contenu vient d'être aimé, le compteur augmente ; s'il est retiré des favoris, il diminue.

Attendu

  • Garder un état aimé / non aimé.
  • Ecouter le clic sur le bouton.
  • Changer le compteur selon l'état.
  • Mettre à jour le texte du bouton.
  • Ajouter une classe visuelle quand le bouton est actif.

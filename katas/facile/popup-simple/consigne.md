# Popup simple

## Objectif

Ouvrir une popup avec un bouton, puis la fermer avec une croix.

## Notions de cours

- Une popup peut etre cachee par defaut en CSS.
- JavaScript peut ajouter une classe pour l'afficher.
- Deux boutons peuvent modifier le meme etat.

## Travail attendu

- Cliquer sur "Ouvrir" affiche la popup.
- Cliquer sur la croix ferme la popup.
- Le fond sombre apparait seulement quand la popup est ouverte.

## Contraintes

- Utiliser `querySelector`.
- Utiliser deux `addEventListener`.
- Ne pas utiliser `alert`.

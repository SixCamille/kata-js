Étoiles de notation

Un clic sur une étoile doit colorer toutes les étoiles jusqu'à cette note.

La note choisie devient l'état principal du composant. Par exemple, si l'utilisateur choisit 3, les trois premières étoiles sont actives et le texte indique cette sélection.

Attendu

  • Sélectionner les cinq boutons étoile.
  • Ecouter le clic sur chaque étoile.
  • Mémoriser la note choisie.
  • Colorer les étoiles actives.
  • Afficher la note sélectionnée.

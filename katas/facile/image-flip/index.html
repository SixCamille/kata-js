Kata facile

Image qui flip

La carte doit afficher son verso au clic, puis revenir au recto au clic suivant.

Le clic alterne un état retourné / non retourné. Le JavaScript décide de l'état, le CSS peut ensuite gérer l'effet visuel de rotation.

Attendu

  • Sélectionner la carte.
  • Ecouter le clic.
  • Ajouter ou retirer une classe d'état.

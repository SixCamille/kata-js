# Jeu d'esquive simple

## Objectif

Deplacer un personnage pour eviter des obstacles mobiles.

## Notions de cours

- Le joueur se deplace au clavier.
- Les obstacles bougent automatiquement.
- Une collision peut etre detectee en comparant des rectangles.
- Un etat de jeu indique si la partie continue ou est perdue.

## Travail attendu

- Deplacer le joueur avec les fleches gauche et droite.
- Faire descendre les obstacles.
- Detecter quand un obstacle touche le joueur.
- Afficher un message de fin si collision.

## Contraintes

- Rester sur une version simple avec quelques obstacles.
- Prioriser la logique JavaScript avant le score ou les effets visuels.

Puzzle réordonnable

Les pièces doivent pouvoir être réordonnées et le message doit indiquer quand l'ordre est correct.

Le drag sert ici à modifier un ordre, pas seulement à déplacer un élément librement. Après chaque échange, l'interface doit pouvoir comparer l'ordre visible avec l'ordre attendu.

Attendu

  • Rendre les pièces déplaçables.
  • Mémoriser la pièce déplacée.
  • Autoriser le dépôt sur les autres pièces.
  • Échanger deux positions.
  • Vérifier si l'ordre final est correct.

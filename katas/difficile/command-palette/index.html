Command palette

La palette de couleurs doit s'ouvrir au clavier, se piloter avec les touches et appliquer la couleur choisie au fond de la page.

On cherche le comportement d'une palette d'application : une commande ouvre ou ferme le panneau, les flèches déplacent l'élément actif, un indicateur visuel montre le bouton sélectionné et Entrée valide la couleur.

Attendu

  • Prévoir une palette avec 5 boutons représentant chacun une couleur.
  • Ouvrir et fermer la palette avec une commande clavier, par exemple Ctrl + K.
  • Ouvrir et fermer la palette avec les boutons prévus dans l'interface.
  • Naviguer entre les boutons avec ArrowLeft, ArrowRight, ArrowUp ou ArrowDown.
  • Afficher clairement le bouton actuellement sélectionné.
  • Valider avec Enter pour changer la couleur du fond.
  • Permettre aussi le clic sur un bouton de couleur pour appliquer cette couleur.
  • Fermer la palette avec Escape.

Kanban persistant

Le tableau doit permettre d'ajouter des cartes, de les faire avancer entre trois colonnes, puis de retrouver l'état après rechargement.

Le point important est de ne pas considérer le HTML comme la source de vérité. Les cartes doivent exister dans un tableau d'objets JavaScript, être rendues dans le DOM, puis être sauvegardées sous forme de texte dans localStorage.

Attendu

  • Garder les cartes dans un tableau d'objets avec au moins un identifiant, un titre et un statut.
  • Créer une carte depuis le formulaire d'ajout.
  • Afficher chaque carte dans la colonne correspondant à son statut.
  • Permettre de déplacer une carte vers la colonne précédente ou suivante.
  • Permettre de supprimer une carte précise.
  • Sauvegarder le tableau complet après chaque modification.
  • Relire les données sauvegardées au chargement de la page.

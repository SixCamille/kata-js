# Attraper les objets

## Objectif

Deplacer un panier pour recuperer des objets qui tombent.

## Notions de cours

- Le panier peut suivre la souris ou le clavier.
- Les objets tombent en changeant de position.
- Une collision simple permet de savoir si l'objet est attrape.
- Un score se met a jour dans le DOM.

## Travail attendu

- Deplacer le panier horizontalement.
- Faire tomber des objets depuis le haut.
- La balle de départ pop aléatoirement en haut du parent, pas toujours à la même position.
- Detecter les objets attrapes.
- Augmenter le score.

## Contraintes

- Garder une version courte et lisible.
- Un seul type d'objet suffit.

Kata difficile

Chrono + todo

Construire deux petits etats qui cooperent : le temps ecoule et la liste des taches.

Attendu

  • Demarrer et mettre en pause le chronometre.
  • Ajouter des taches via le submit.
  • Stocker les taches dans un tableau et refaire le rendu.

Notions du pense-bete

Temps

setInterval repete une action jusqu'a clearInterval.

const timerId = setInterval(function () {
  seconds = seconds + 1;
}, 1000);

clearInterval(timerId);

Tableaux

Un tableau stocke plusieurs valeurs dans un ordre et peut servir de source pour le rendu.

const tasks = [];
tasks.push({ label: "Relire la consigne", done: false });

Specifique au kata

Submit d'un formulaire

Sur un submit, empeche le rechargement pour garder l'application sur la page.

form.addEventListener("submit", function (event) {
  event.preventDefault();
});

Vider puis reconstruire

Refaire le rendu depuis le tableau aide a synchroniser l'ecran avec l'etat courant.

list.innerHTML = "";

tasks.forEach(function (task) {
  const item = document.createElement("li");
  item.textContent = task.label;
  list.append(item);
});

# Chronometre de todo list

## Objectif

Créer une petite todo list associee a un chronometre de session.

## Notions de cours

- Un formulaire permet de recuperer proprement une saisie utilisateur.
- Un tableau peut representer l'etat d'une liste.
- Un rendu DOM doit etre mis a jour quand l'etat change.
- `setInterval` permet de compter le temps ecoule.
- Une fonctionnalite plus riche se construit en combinant plusieurs petits etats.

## Travail attendu

La page doit permettre de :

- demarrer et mettre en pause le chronometre ;
- ajouter une tache depuis le formulaire ;
- afficher les taches dans la liste ;
- cocher une tache comme faite ;
- afficher le nombre de taches terminees.

## Contraintes

- Utiliser un tableau pour stocker les taches.
- Utiliser `submit` pour le formulaire.
- Utiliser `setInterval` et `clearInterval`.
- Ne pas recharger la page a l'ajout d'une tache.
- Ne pas utiliser de bibliotheque externe.

Filtre produits

Les boutons de catégorie doivent afficher uniquement les produits concernés.

Le tableau de produits sert de source de données. Quand une catégorie est choisie, l'affichage est reconstruit avec les produits qui correspondent à ce filtre.

Attendu

  • Préparer une liste de produits avec une catégorie.
  • Ecouter les boutons de filtre.
  • Filtrer selon la catégorie choisie.
  • Vider la liste affichée.
  • Reconstruire les cartes visibles.

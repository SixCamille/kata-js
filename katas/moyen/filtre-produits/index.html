Filtre produits

Les boutons de catégorie doivent afficher uniquement les produits concernés.

La liste de produits du starter contient déjà une catégorie par élément. Quand une catégorie est choisie, l'affichage garde seulement les produits qui correspondent à ce filtre.

Attendu

  • Repérer la catégorie demandée par le bouton cliqué.
  • Ecouter les boutons de filtre.
  • Afficher tous les produits avec le filtre Tous.
  • Afficher uniquement les fruits ou les légumes selon le filtre choisi.
  • Mettre à jour l'état visuel du bouton actif.

Autocomplétion

Une liste de suggestions doit se filtrer pendant la saisie.

Chaque frappe produit une nouvelle liste visible. Si l'utilisateur tape quelques lettres, seules les suggestions pertinentes restent affichées ; si le champ est vide, l'affichage doit rester maîtrisé.

Attendu

  • Stocker les suggestions dans un tableau.
  • Ecouter l'événement input.
  • Filtrer selon le texte saisi.
  • Reconstruire la liste de resultats.

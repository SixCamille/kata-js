Kata moyen

Suivre le pointeur

Les pupilles doivent se deplacer legerement vers la position actuelle de la souris.

Attendu

  • Ecouter l'evenement mousemove.
  • Calculer le centre de chaque oeil.
  • Appliquer un transform limite aux pupilles.

Notions du pense-bete

Souris

Sur un evenement de souris, on peut lire la position du pointeur dans la fenetre.

document.addEventListener("mousemove", function (event) {
  console.log(event.clientX, event.clientY);
});

Modifier un element

Le DOM peut modifier le style d'un element en reaction a l'utilisateur.

pupil.style.transform = "translate(8px, -4px)";

Specifique au kata

Position d'un element

La boite d'un element permet de calculer son centre dans la fenetre.

const rect = element.getBoundingClientRect();
const centerX = rect.left + rect.width / 2;
const centerY = rect.top + rect.height / 2;

Limiter une valeur

Limiter le deplacement evite que la pupille sorte trop loin de l'oeil.

const limited = Math.max(-12, Math.min(12, value));

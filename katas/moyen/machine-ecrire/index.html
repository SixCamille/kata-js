Machine à écrire

Le texte doit apparaître lettre par lettre après le clic.

Le texte complet existe dès le départ, mais l'interface n'en montre qu'une partie. À chaque étape, on avance l'index pour révéler une lettre de plus.

Attendu

  • Stocker le texte complet.
  • Garder l'index de la lettre courante.
  • Lancer un intervalle au clic.
  • Ajouter progressivement les lettres à l'écran.
  • Arrêter l'intervalle quand le texte est complet.

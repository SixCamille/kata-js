Todo enrichie

La liste doit gérer l'ajout de tâches, leur validation immédiate et le nombre de tâches encore à faire.

Le tableau de tâches actives devient la source de vérité. Quand une tâche est cochée ou supprimée, elle sort du tableau, puis l'affichage est reconstruit à partir des données restantes.

Attendu

  • Ajouter une tâche depuis le formulaire.
  • Stocker uniquement les tâches actives dans un tableau.
  • Reconstruire la liste visible après chaque action.
  • Retirer une tâche quand elle est cochée comme terminée.
  • Supprimer une tâche sans la terminer, puis mettre à jour le compteur.

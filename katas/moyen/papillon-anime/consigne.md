# Papillon anime

## Objectif

Faire traverser l'ecran a un papillon en donnant l'impression qu'il bat des ailes.

## Notions de cours

- Une classe CSS peut declencher une animation.
- Un element peut etre deplace avec `transform`.
- `setTimeout` peut servir a reinitialiser l'animation.

## Travail attendu

- Un clic sur le bouton lance le vol.
- Le papillon traverse la zone de gauche a droite.
- Les ailes battent pendant le deplacement.
- Le papillon peut repartir apres la fin de l'animation.

## Contraintes

- Ne pas recreer le papillon a chaque clic.
- Utiliser une classe d'etat pour lancer l'animation.

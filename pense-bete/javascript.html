Notions JavaScript

Facile Moyen Difficile Pense-bete Picker

01

Variables

const sert pour une reference que l'on ne reassigne pas. let sert pour une valeur qui peut changer.

const button = document.querySelector("button");
let count = 0;

02

Conditions

Une condition permet de choisir un comportement selon l'etat actuel.

if (count > 5) {
  message.textContent = "Bravo";
} else {
  message.textContent = "Continue";
}

03

Fonctions

Une fonction regroupe une action que l'on veut nommer, declencher ou reutiliser.

function updateMessage(text) {
  message.textContent = text;
}

04

Tableaux

Un tableau stocke plusieurs valeurs dans un ordre. On le parcourt souvent avec forEach.

const colors = ["red", "blue", "green"];
colors.push("gold");

colors.forEach(function (color) {
  console.log(color);
});

05

Selectionner dans le DOM

querySelector recupere le premier element qui correspond au selecteur CSS. querySelectorAll recupere une liste.

const title = document.querySelector("h1");
const card = document.querySelector(".card");
const buttons = document.querySelectorAll("button");

06

Modifier un element

Le DOM peut changer son texte, ses classes ou certains styles en reaction a l'utilisateur.

title.textContent = "Nouveau titre";
card.classList.add("active");
card.classList.remove("hidden");
card.style.transform = "translateX(20px)";

07

Ecouter un evenement

addEventListener relie une action utilisateur ou navigateur a une fonction.

button.addEventListener("click", function () {
  count = count + 1;
});
  • click
  • input
  • submit
  • mousemove
  • keydown
  • scroll

08

Temps

setTimeout lance une action une seule fois. setInterval repete une action jusqu'a clearInterval.

setTimeout(function () {
  message.textContent = "Temps ecoule";
}, 1000);

const timerId = setInterval(function () {
  count = count + 1;
}, 1000);

clearInterval(timerId);

09

Souris

Sur un evenement de souris, on peut lire la position du pointeur dans la fenetre.

document.addEventListener("mousemove", function (event) {
  console.log(event.clientX, event.clientY);
});

10

Scroll

window.scrollY indique de combien la page a defile verticalement.

window.addEventListener("scroll", function () {
  console.log(window.scrollY);
});

Debug

Quand ca bloque, reduire le probleme.

  • Lire la console.
  • Verifier que le fichier JS est bien charge.
  • Tester un console.log dans chaque evenement.
  • Inspecter les classes dans les DevTools.
  • Nommer les variables selon leur role.
  • Avancer petit a petit.
